# ProductsImport

Windows-приложение (WinForms, .NET 8) для импорта товаров из прайс-листа/накладной
Excel (`.xlsx`, `.xls`) или `.csv` в справочник товаров MS SQL Server
(таблицы `ass1`, `ass2`, `ass3`, `ass4`, `gru2`, `cls2`, `nds1`) — замена
ручному запуску T-SQL скрипта импорта.

## Возможности

- **Подключения к БД.** Окно настроек подключения (сервер, база, логин/пароль
  или Windows-аутентификация) с сохранением списка подключений в
  `%AppData%\ProductsImport\connections.json`. Пароль хранится в
  зашифрованном виде (Windows DPAPI, привязан к пользователю Windows).
- **Открытие документа.** `.xlsx`/`.xls` читаются через NPOI, `.csv` —
  встроенным парсером с автоопределением разделителя (`,`, `;`, Tab).
  Можно выбрать лист и указать строку, с которой начинается шапка таблицы —
  импорт пойдёт со следующей строки.
- **Сопоставление колонок.** Каждую колонку документа можно сопоставить с
  полем справочника: наименование (обязательно), штрих-код, группа,
  артикул, весовой (да/нет), единица измерения, НДС, подакцизный (да/нет).
- **Значения по умолчанию.** Если колонка не сопоставлена или в части строк
  значение не указано/не распознано — программа предложит выбрать группу,
  единицу измерения и ставку НДС из справочника БД, а также значения
  "весовой"/"подакцизный" по умолчанию.
- **Обработка штрих-кода.** Для строк без штрих-кода, с некорректным
  штрих-кодом (не 8/12/13 цифр) или с штрих-кодом, который уже занят другим
  товаром, — отдельное окно, где для каждой строки (или сразу для всех)
  выбирается действие: сгенерировать уникальный EAN-13, не импортировать
  строку или ввести штрих-код вручную.
- **Артикул.** Если в документе нет артикула или он не указан в строке —
  автоматически берётся наименьший свободный номер `ass1001`. Если указанный
  в документе артикул уже занят другим товаром — строка помечается ошибкой.
- **Импорт по одной строке в собственной транзакции**, поэтому ошибка в одной
  строке не блокирует импорт остальных.
- **Отчёт об ошибках.** Строки, которые не удалось импортировать (нет
  наименования, не удалось определить группу/единицу/НДС, конфликт артикула,
  ошибка БД, пропущено пользователем и т.д.), собираются в список и могут
  быть сохранены в отдельный `.xlsx`-файл — с исходными данными строки и
  причиной ошибки — для исправления и повторного импорта.

## Структура решения

```
ProductsImport.sln
ProductsImport/
  Program.cs                     — точка входа
  Models/                        — модели данных (ConnectionProfile, GroupInfo,
                                    UnitInfo, VatInfo, ColumnMapping, ImportRow, ...)
  Data/
    ConnectionProfileStore.cs    — хранение сохранённых подключений (JSON)
    SqlServerRepository.cs       — весь доступ к ass1/ass2/ass3/ass4/gru2/cls2/nds1
  Services/
    SpreadsheetReader.cs         — чтение xlsx/xls/csv
    BarcodeGenerator.cs          — валидация и генерация EAN-13
    ArticleAllocator.cs          — выдача наименьшего свободного артикула
    ErrorReportService.cs        — выгрузка ошибок в xlsx
    ImportOrchestrator.cs        — сопоставление полей, применение умолчаний,
                                    запуск импорта
  Forms/
    MainForm.cs                  — главное окно (подключение, файл, лист, импорт)
    ConnectionSettingsForm.cs / ConnectionEditForm.cs
    ColumnMappingForm.cs
    DefaultsForm.cs
    BarcodeIssuesForm.cs / ManualBarcodeForm.cs
    ImportResultForm.cs
```

## Сборка

1. Установите **Visual Studio 2022** (17.8+) с нагрузкой **.NET desktop
   development** (нужен .NET 8 SDK — ставится вместе с этой нагрузкой либо
   отдельно с https://dotnet.microsoft.com).
2. Откройте `ProductsImport.sln`.
3. Visual Studio восстановит NuGet-пакеты автоматически (`Microsoft.Data.SqlClient`,
   `NPOI`, `System.Security.Cryptography.ProtectedData`) при первой сборке.
4. Соберите решение (`Ctrl+Shift+B`) и запустите `ProductsImport`.

Либо из командной строки Windows с установленным .NET 8 SDK:

```
dotnet build ProductsImport.sln -c Release
```

Готовый исполняемый файл будет в
`ProductsImport\bin\Release\net8.0-windows\ProductsImport.exe`.

## Соответствие таблицам БД

Логика вставки повторяет исходный T-SQL скрипт импорта:

- `ass1` (`ass1001..ass1007`) — артикул, наименование, НДС (`nds1001`),
  единица измерения (`cls2001`, где `cls2002 = 100`), весовой, подакцизный.
- `ass2` — дублирует артикул/наименование, остальные колонки заполняются
  теми же константами по умолчанию, что и в исходном скрипте.
- `ass3` — штрих-код товара.
- `ass4` — привязка товара к группе (`gru2001`, где `gru2002 = 1`).

## Замечание о лицензии NPOI

Библиотека NPOI (чтение/запись Excel) распространяется с условиями,
описанными в её EULA (см. страницу пакета на nuget.org) — при коммерческом
использовании стоит ознакомиться с ними отдельно.
