# ProductsImport

Windows-приложение (WinForms, .NET Framework 4.8) для импорта товаров из
прайс-листа/накладной Excel (`.xlsx`, `.xls`) или `.csv` в справочник товаров
MS SQL Server (таблицы `ass1`, `ass2`, `ass3`, `ass4`, `gru2`, `cls2`, `nds1`)
— замена ручному запуску T-SQL скрипта импорта.

## Возможности

Всё происходит в одном окне («Импорт товаров в справочник») — вместо цепочки
всплывающих диалогов нужные разделы (сопоставление колонок, значения по
умолчанию, решение по штрих-коду) появляются прямо под таблицей документа по
мере необходимости.

- **Подключения к БД.** Окно настроек подключения (сервер, база, логин/пароль
  или Windows-аутентификация) со списком сохранённых подключений. Двойной
  щелчок по строке в списке применяет это подключение и сразу закрывает
  окно (аналогично кнопке «Выбрать»). Пароль хранится в зашифрованном виде
  (Windows DPAPI, привязан к пользователю Windows). При запуске программы
  автоматически применяется последнее использованное подключение (и сразу
  запрашиваются справочные данные — группы, единицы измерения, НДС).
- **Открытие документа.** `.xlsx`/`.xls` читаются через NPOI, `.csv` —
  встроенным парсером с автоопределением разделителя (`,`, `;`, Tab). Можно
  выбрать лист и указать строку, с которой начинается шапка таблицы — либо
  через поле «Строка с заголовками», либо кликом по нужной строке прямо в
  таблице предпросмотра документа. Импорт пойдёт со следующей строки.
- **Сопоставление колонок** — раздел «Сопоставление колонок» под таблицей
  документа. Каждую колонку можно сопоставить с полем справочника:
  наименование (обязательно), штрих-код, группа, артикул, весовой (да/нет),
  единица измерения, НДС (%, автоматически по числовому проценту), налоговая
  ставка (по явному сопоставлению — см. ниже), подакцизный (да/нет), УКТЗЕД
  (`ass2031`). УКТЗЕД необязателен: если колонки нет или ячейка пустая —
  значение просто не заполняется. Поле, уже выбранное для одной колонки,
  пропадает из списка выбора для остальных колонок (чтобы не сопоставить его
  дважды по ошибке) и появляется снова, как только выбор для этой колонки
  сняли.
- **Группа товаров.** Если колонка «Группа» сопоставлена: значение ячейки,
  совпадающее с названием (или кодом) существующей группы — используется эта
  группа; значение, которого нет в справочнике — группа создаётся в БД
  (`gru2`) и используется для этого товара; пустая ячейка — используется
  «Группа товаров по умолчанию». Кнопка «Сопоставление групп товаров»
  открывает список всех товаров текущего импорта, где для каждого (или для
  нескольких выделенных строк — с Shift, Ctrl или Ctrl+A) можно вручную
  указать группу из БД взамен автоматически определённой.
- **Налоговая ставка.** Если колонке сопоставлено назначение «Налоговая
  ставка» (а не «НДС, %»), её значения не пытаются разобрать как процент —
  вместо этого работает явное сопоставление, заданное в отдельном окне.
  Кнопка «Сопоставление налоговых групп» (активна, когда «Налоговая ставка»
  сопоставлена) показывает список уникальных значений этой колонки в
  документе, где каждому можно назначить ставку НДС из БД; для пустых ячеек
  или значений без сопоставления используется «Налоговая ставка по
  умолчанию».
- **Подакцизность.** Если колонка «Подакцизный (да/нет)» сопоставлена,
  кнопка «Сопоставление акцизности товара» показывает список уникальных
  значений этой колонки, где каждому можно назначить «Да» или «Нет» — это
  сопоставление имеет приоритет. Если сопоставления для значения нет,
  используются слова да/д/yes/y/1/true/истина (→ `ass1007`/`ass2010` = 1) и
  нет/н/no/n/0/false/ложь (→ 0), без учёта регистра и с обрезкой пробелов;
  для пустых ячеек и нераспознанных значений — «Подакцизность по умолчанию».
- **Значения по умолчанию** — раздел «Значения по умолчанию»: группа,
  единица измерения, налоговая ставка, весовой и подакцизный по умолчанию.
  Применяются, если соответствующая колонка не сопоставлена или значение в
  ячейке не распознано (и не покрыто явным сопоставлением групп/налоговых
  ставок/акцизности); при запуске импорта программа предупредит, если
  фактически нужное значение по умолчанию не выбрано.
- **Профили импорта.** Строку заголовков, сопоставление колонок и значения
  по умолчанию можно сохранить под именем и повторно применить при импорте
  документа с такой же структурой, но другим содержанием товаров (например,
  регулярный прайс-лист от одного и того же поставщика). Кнопка «Сохранить
  как профиль...» сохраняет текущее состояние всех трёх разделов. Чтобы
  изменить профиль — выберите его, поправьте разделы и сохраните заново под
  тем же именем. При выборе профиля строка заголовков, сопоставление колонок
  и значения по умолчанию подставляются автоматически. При следующем запуске
  программы автоматически применяется последний использованный профиль.
  Сопоставление групп/налоговых ставок/акцизности (по конкретным значениям
  документа) в профиль не сохраняется — оно относится к содержимому
  конкретного файла, а не к его структуре.
- **Обработка штрих-кода** — раздел «Требуется решение по штрих-коду»,
  появляющийся при нажатии «Начать импорт», если в документе есть строки без
  штрих-кода, с некорректным штрих-кодом (не 8/12/13 цифр) или с штрих-кодом,
  который уже занят другим товаром. Для каждой строки (или сразу для всех)
  выбирается действие: сгенерировать уникальный EAN-13, не импортировать
  строку или ввести штрих-код вручную; после этого кнопка «Начать импорт»
  превращается в «Импортировать».
- **Артикул.** Если в документе нет артикула или он не указан в строке —
  автоматически берётся наименьший свободный номер `ass1001`. Если указанный
  в документе артикул уже занят другим товаром — строка помечается ошибкой.
- **Импорт по одной строке в собственной транзакции**, поэтому ошибка в одной
  строке не блокирует импорт остальных.
- **Отчёт об ошибках.** Строки, которые не удалось импортировать (нет
  наименования, не удалось определить группу/единицу/НДС, конфликт артикула,
  ошибка БД, пропущено пользователем и т.д.), собираются в список и могут
  быть сохранены в отдельный `.xlsx`-файл — с исходными данными строки и
  причиной ошибки — для исправления и повторного импорта.
- **Все настройки — рядом с программой.** Подключения, профили импорта и
  последнее использованное подключение/профиль/настройки хранятся в
  JSON-файлах в папке `config` рядом с `ProductsImport.exe` (а не в
  `%AppData%`), так что переносятся вместе с программой. Если программа
  установлена в защищённую системную папку (например, `Program Files`), для
  записи в `config` понадобятся права на запись в папку программы — при
  обычной установке в пользовательскую папку это не требует прав
  администратора.

## Структура решения

```
ProductsImport.sln
ProductsImport/
  Program.cs                     — точка входа
  Models/                        — модели данных (ConnectionProfile, ImportProfile, AppSettings,
                                    GroupInfo, UnitInfo, VatInfo, ColumnMapping, ImportRow, ...)
  Data/
    JsonStore.cs                 — общее сохранение/чтение JSON-файлов (списков и объектов)
                                    из папки config рядом с exe
    ConnectionProfileStore.cs    — хранение сохранённых подключений
    ImportProfileStore.cs        — хранение сохранённых профилей импорта (заголовок + колонки)
    AppSettingsStore.cs          — хранение последнего использованного подключения/профиля/настроек
    SqlServerRepository.cs       — весь доступ к ass1/ass2/ass3/ass4/gru2/cls2/nds1
  Services/
    SpreadsheetReader.cs         — чтение xlsx/xls/csv
    BarcodeGenerator.cs          — валидация и генерация EAN-13
    ArticleAllocator.cs          — выдача наименьшего свободного артикула
    ErrorReportService.cs        — выгрузка ошибок в xlsx
    ImportOrchestrator.cs        — сопоставление полей, применение умолчаний,
                                    запуск импорта
  Forms/
    MainForm.cs                  — главное окно: подключение, файл, лист, профили импорта,
                                    сопоставление колонок, значения по умолчанию, решение по
                                    штрих-коду и запуск импорта — всё в одном окне
    ConnectionSettingsForm.cs / ConnectionEditForm.cs
    ValueMappingForm.cs          — сопоставление уникальных значений документа со значением из
                                    БД (налоговые ставки, акцизность)
    ProductGroupMappingForm.cs   — сопоставление групп по каждому товару (с множественным выбором строк)
    ManualBarcodeForm.cs         — ввод штрих-кода вручную для одной строки
    ImportResultForm.cs
    TextPromptForm.cs            — общий диалог ввода строки (например, имени профиля)
```

## Сборка

1. Установите **Visual Studio 2022** с нагрузкой **.NET desktop development**
   (включает .NET Framework 4.8 targeting pack; при необходимости его также
   можно поставить отдельно — https://dotnet.microsoft.com/download/dotnet-framework/net48).
2. Откройте `ProductsImport.sln`.
3. Visual Studio восстановит NuGet-пакеты автоматически (`Microsoft.Data.SqlClient`,
   `NPOI`) при первой сборке.
4. Соберите решение (`Ctrl+Shift+B`) и запустите `ProductsImport`.

Либо из командной строки Windows (Developer Command Prompt / .NET SDK):

```
dotnet build ProductsImport.sln -c Release
```

Готовый исполняемый файл будет в
`ProductsImport\bin\Release\net48\ProductsImport.exe`.

## Соответствие таблицам БД

Логика вставки повторяет исходный T-SQL скрипт импорта:

- `ass1` (`ass1001..ass1007`) — артикул, наименование, НДС (`nds1001`),
  единица измерения (`cls2001`, где `cls2002 = 100`), весовой, подакцизный.
- `ass2` — дублирует артикул/наименование, `ass2010` — подакцизный (1/0,
  раньше было захардкожено в `2`), `ass2031` — УКТЗЕД (пусто, если не
  сопоставлено или не заполнено), остальные колонки заполняются теми же
  константами по умолчанию, что и в исходном скрипте.
- `ass3` — штрих-код товара.
- `ass4` — привязка товара к группе (`gru2001`, где `gru2002 = 1`).
- `gru2` — новая группа создаётся автоматически (`gru2002 = 1`,
  `gru2003 = gru2001 + 100`, следующий свободный `gru2001`), когда значение
  колонки «Группа» не совпадает ни с одной существующей группой.

## Замечание о лицензии NPOI

Библиотека NPOI (чтение/запись Excel) распространяется с условиями,
описанными в её EULA (см. страницу пакета на nuget.org) — при коммерческом
использовании стоит ознакомиться с ними отдельно.
